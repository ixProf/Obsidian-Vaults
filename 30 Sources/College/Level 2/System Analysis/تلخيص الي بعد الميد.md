- ### How Do Web Pages Work?
	
	1. Type in a URL, Which is the address of the html file on the internet
	2. The browser asks the web server that hosts the document to send that document.
	3. The web server responds to the browser with HTML file that was requested.
	4. The browser reads the HTML, sees the embedded resources and asks the server for those as well.
	5. The web page is loaded when all the resources are fetched and displayed.

		- What are browsers ?
			- Browsers are applications that can display web pages.
			- Web pages are written in a ==markup language== called ==HTML==
			- The HTML file might link to other resources, like images, videos, as well as JavaScript and ==CSS (stylesheet)== files
		- What's the Web Server?
			- is a program running on a computer that delivers web pages in response to requests.

### The current technology: Web service/microservice
- **Web services** are made of independent software components that **exchange data using standard web languages**.
    
- They can **connect different systems**, even if they use **different operating systems or programming languages**.
    
- They can link **systems between organizations** or **within one company**.
    
- Web services allow different apps to **communicate easily**, without needing **custom code** every time.

- A **Service-Oriented Architecture (SOA)** is a system made up of **self-contained services** that work together to build software applications.
    
- **Business tasks** are completed by executing a series of these services.
    
- Developers can **reuse** the same services in different combinations to create new applications.
    
- **Large companies** may use **thousands of microservices** to support their systems.

### Cloud Computing:
**Cloud Computing**: is a model that makes computing resources (like servers, networks, storage, and software) available over a network, typically accessed through a web browser, and configurable for use with any computing device

Examples:
- Windows-365
- Google Co-Lab

- **Cloud Computing Characteristics:**
	- Provides On-Demand Self-Service
	- Encompasses the Characteristics of Grid and Utility Computing
	- Uses Broad Network Access
		- The cloud provider’s computing resources are available over a network, accessed with a web browser, and they are configured so that they can be used with any computing device.
	- Pools Computing Resources
	- Often Occurs on Virtualized Servers

#### Public , Private and Hybrid Cloud (متقالتش فالمحاضرة بس علشان تفهم الدنيا)
- **Public cloud** is a cloud service provided by==third-party== vendors over the internet and ==shared among multiple users.==
    
- **Private cloud** is a cloud environment used exclusively by ==one organization==, offering ==more control and security.==
    
- **Hybrid cloud** ==combines both public and private clouds==, allowing data and applications to move between them for ==greater flexibility.==

### SaaS , PaaS and IaaS:
- **Software-as-a-Service** (SaaS): In this model, cloud computing ==vendors provide software specific== to their customers' requirements. ==SaaS is the most widely used== service model, offering a broad range of software applications. Providers typically charge a monthly or yearly subscription fee.
- Platform-as-a-Service (PaaS): ==Customers rent servers==, operating systems, storage, a database, software development technologies (like Java and .NET), and network capacity over the Internet. The PaaS model allows ==customers to run existing applications== and to develop and test new ones.
- Infrastructure-as-a-Service (IaaS): Cloud computing providers ==offer== ==remotely accessible== servers, networks, and storage capacity. These resources are ==supplied on demand== from their large resource pools located in their data centers.
##### the **key differences** between **SaaS**, **PaaS**, and **IaaS**:

| Feature / Model         | **SaaS** (Software as a Service)                | **PaaS** (Platform as a Service)                              | **IaaS** (Infrastructure as a Service)                            |
| ----------------------- | ----------------------------------------------- | ------------------------------------------------------------- | ----------------------------------------------------------------- |
| **Main Purpose**        | Provides ==ready-to-use== software applications | Provides platform for developing, testing, and deploying apps | Provides virtualized computing resources like servers and storage |
| **User Control Over**   | Only application usage                          | Applications and data                                         | Applications, data, runtime, middleware, OS                       |
| **Managed by Provider** | Everything (apps, data, OS, infrastructure)     | Infrastructure, OS, runtime                                   | Only hardware (servers, storage, networking)                      |
| **Accessed By**         | End users                                       | Developers                                                    | IT administrators, system architects                              |
| **Example Use**         | Email, CRM, document editing                    | Building and testing web or mobile apps                       | Hosting websites, data backup, high-performance computing         |
| **Common Examples**     | Google Workspace, Dropbox, Salesforce           | Google App Engine, Microsoft Azure App Services               | Amazon EC2, Microsoft Azure VMs, Google Compute Engine            |
| **Billing Type**        | Subscription (monthly/yearly)                   | Pay-as-you-go for ==platform usage==                          | Pay-as-you-go based on ==resource usage==                         |
