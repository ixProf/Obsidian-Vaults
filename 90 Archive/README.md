# Archive

Superseded, duplicate, or obsolete material that still has value.

## Rules

- Never delete content.
- Move, do not copy, unless the copy is needed as a source.
- Record the reason and the original path.
- Update links after the move.
- Keep archived notes out of domain MOCs unless they are historically relevant.

## Conventions

Use a short header in each archived note:

```markdown
> Archived: 2026-11-01
> Reason: superseded by [[...]]
> Original path: ...
```
