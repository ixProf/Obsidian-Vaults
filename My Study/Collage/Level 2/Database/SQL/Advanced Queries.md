## 🔹 **1. الاستعلامات الفرعية (SubQuery)**

📌 **يعني إيه؟**  
الـ **SubQuery** هو استعلام جواه استعلام تاني، يعني فيه **استعلام داخلي (`Inner Query`)** بيتم استخدامه كمدخل لاستعلام تاني أكبر منه اسمه **الاستعلام الخارجي (`Outer Query`)**.

🚨 **ملحوظة مهمة:**  
الـ **SubQuery بطيء جدًا** ❌ ويفضل ما تستخدموش إلا في حالات معينة بس.

### ✨ **مثال عملي:**

```sql
-- استرجاع الموظفين اللي رواتبهم أعلى من متوسط الرواتب
SELECT Name, Salary 
FROM Employees 
WHERE Salary > (SELECT AVG(Salary) FROM Employees);
```

🔍 **اللي بيحصل هنا:**  
1️⃣
الـ **SubQuery** بيحسب متوسط الرواتب (`AVG(Salary)`).  
2️⃣
الاستعلام الخارجي (`Outer Query`) بيجيب كل الموظفين اللي رواتبهم أعلى من المتوسط.

## 🔹 **2. جلب أعلى القيم (TOP)**

📌 **يعني إيه؟**  
الـ `TOP` بتستخدم عشان تجيب عدد معين من الصفوف بدل ما تجيب كل البيانات.

⚠ **ملحوظة:**  
لو هتستخدم **`TOP WITH TIES`**، لازم يكون معاه **`ORDER BY`** عشان يجيب الصفوف اللي ليها نفس القيمة اللي في آخر صف مختار.

### ✨ **مثال عملي:**

```sql
-- جلب أول 5 موظفين حسب أعلى مرتب
SELECT TOP 5 Name, Salary 
FROM Employees 
ORDER BY Salary DESC;
```

```sql
-- جلب أول 3 موظفين بس لو في أكتر من موظف ليه نفس المرتب هيظهروا كلهم
SELECT TOP 3 WITH TIES Name, Salary 
FROM Employees 
ORDER BY Salary DESC;
```

## 🔹 **3. وظايف الترتيب (Ranking Functions) 📊**

📌 **يعني إيه؟**  
وظايف الترتيب بتساعدك تعمل ترتيب على البيانات زي `RANK()` و `DENSE_RANK()` و `ROW_NUMBER()`.

### ✨ **مثال عملي:**

```sql
-- ترتيب الموظفين حسب المرتب باستخدام `RANK()`
SELECT Name, Salary, 
       RANK() OVER (ORDER BY Salary DESC) AS Rank
FROM Employees;
```

🔍 **اللي بيحصل هنا:**  
كل موظف بياخد **رقم ترتيب** حسب المرتب بتاعه، ولو في موظفين ليهم نفس المرتب بياخدوا نفس الترتيب ويتخطى الرقم اللي بعدهم.

التلات دوال دول بيستخدموا لترتيب البيانات بناءً على عمود معين، لكن الفرق بينهم في كيفية التعامل مع القيم المتساوية. هوضحلك الفرق بينهم بمثال عملي.

---

## 🔹 **الفرق بين `RANK()` و `DENSE_RANK()` و `ROW_NUMBER()`**

📌 **جدول الموظفين (Employees) كمثال:**

|ID|Name|Salary|
|---|---|---|
|1|Ali|5000|
|2|Omar|7000|
|3|Nada|7000|
|4|Sara|6000|
|5|Karim|5000|

---

### **1️⃣ `RANK()`**

🔍 **بيرتب البيانات، لكن لو فيه قيم متساوية بياخدوا نفس الترتيب، وبعدهم بيتم تخطي الأرقام.**

```sql
SELECT Name, Salary, 
       RANK() OVER (ORDER BY Salary DESC) AS Rank
FROM Employees;
```

💡 **النتيجة:**

| Name  | Salary | Rank |
| ----- | ------ | ---- |
| Omar  | 7000   | 1    |
| Nada  | 7000   | 1    |
| Sara  | 6000   | 3    |
| Ali   | 5000   | 4    |
| Karim | 5000   | 4    |

🔎 **الملاحظة:** بعد 7000 (اللي ليها ترتيب 1)، القيم اللي بعدها أخدت 3 مش 2! لإنه تخطى الرقم 2.

---

### **2️⃣ `DENSE_RANK()`**

🔍 **بيشتغل زي `RANK()` لكن الفرق إنه مبيعملش تخطي في الأرقام بعد القيم المتساوية.**

```sql
SELECT Name, Salary, 
       DENSE_RANK() OVER (ORDER BY Salary DESC) AS DenseRank
FROM Employees;
```

💡 **النتيجة:**

|Name|Salary|DenseRank|
|---|---|---|
|Omar|7000|1|
|Nada|7000|1|
|Sara|6000|2|
|Ali|5000|3|
|Karim|5000|3|

🔎 **الملاحظة:** هنا بعد 7000 (اللي ليها ترتيب 1)، الرقم اللي بعده بقى 2 مش 3، لإن `DENSE_RANK()` مبيسيبش فراغات.

---

### **3️⃣ `ROW_NUMBER()`**

🔍 **بيدي رقم لكل صف بدون أي تكرار حتى لو القيم متساوية.**

```sql
SELECT Name, Salary, 
       ROW_NUMBER() OVER (ORDER BY Salary DESC) AS RowNum
FROM Employees;
```

💡 **النتيجة:**

|Name|Salary|RowNum|
|---|---|---|
|Omar|7000|1|
|Nada|7000|2|
|Sara|6000|3|
|Ali|5000|4|
|Karim|5000|5|

🔎 **الملاحظة:** كل صف بياخد رقم فريد حتى لو المرتب متكرر، وده الفرق الأساسي عن `RANK()` و `DENSE_RANK()`.

---

## 🔹 **ملخص الفرق بينهم**

|الدالة|هل بيديلك رقم فريد؟|هل فيه تخطي في الترتيب؟|
|---|---|---|
|`RANK()`|❌ لا، القيم المتساوية بتاخد نفس الترتيب|✅ آه، بيتم تخطي الأرقام|
|`DENSE_RANK()`|❌ لا، القيم المتساوية بتاخد نفس الترتيب|❌ لا، مفيش تخطي للأرقام|
|`ROW_NUMBER()`|✅ آه، كل صف بياخد رقم فريد|❌ لا، مفيش تخطي للأرقام|

🎯 **الاختيار بينهم بيعتمد على الحاجة:**

- لو عايز **ترتيب مع تخطي الأرقام** → استخدم `RANK()`.
- لو عايز **ترتيب متسلسل بدون تخطي** → استخدم `DENSE_RANK()`.
- لو عايز **رقم لكل صف بغض النظر عن التكرار** → استخدم `ROW_NUMBER()`.

## 🔹 **4. ترتيب تنفيذ الاستعلامات (Execution Order) ⏳**

📌 **يعني إيه؟**  
لما بتكتب استعلام SQL، التنفيذ بيتم بترتيب معين، مش بنفس الترتيب اللي بتكتبه بيه.

💡 **ترتيب التنفيذ بيكون كالتالي:**  
1️⃣ **FROM** – الأول بنحدد الجدول اللي هنشتغل عليه.  
2️⃣ **JOIN/ON** – لو فيه ربط بين جداول، بيتنفذ هنا.  
3️⃣ **WHERE** – الفلترة على الصفوف بتتم هنا.  
4️⃣ **GROUP BY** – تجميع البيانات على حسب قيمة معينة.  
5️⃣ **HAVING** – الفلترة على النتائج بعد `GROUP BY`.  
6️⃣ **SELECT** – تحديد الأعمدة اللي عاوز تعرضها.  
7️⃣ **DISTINCT** – حذف القيم المكررة.  
8️⃣ **ORDER BY** – ترتيب النتائج.  
9️⃣ **TOP** – تحديد عدد الصفوف اللي هتظهر.

### ✨ **مثال عملي:**

```sql
SELECT TOP 5 Department, AVG(Salary) AS AvgSalary
FROM Employees
WHERE Salary > 3000
GROUP BY Department
HAVING AVG(Salary) > 5000
ORDER BY AvgSalary DESC;
```

🔍 **اللي بيحصل هنا بالترتيب:**  
1️⃣ نختار جدول الموظفين.  
2️⃣ نفلتر بس الموظفين اللي رواتبهم فوق 3000.  
3️⃣ نجمع البيانات حسب القسم (`GROUP BY`).  
4️⃣ نفلتر بس الأقسام اللي فيها متوسط مرتبات أعلى من 5000 (`HAVING`).  
5️⃣ نرتب النتائج من الأعلى للأقل (`ORDER BY`).  
6️⃣ نعرض **أول 5 صفوف بس (`TOP 5`)**.

## 🔹 **5. الـ Schema في قواعد البيانات 🗂️**

📌 **يعني إيه؟**  
الـ **Schema** هو حاجة زي "تصنيف" أو "تنظيم" للجداول والوظايف في قاعدة البيانات.

💡 **ليه مهم؟**  
1️⃣**بيمنعك من تكرار أسماء الجداول والكائنات** في نفس الـ Database.  
2️⃣**بيساعدك تدي معنى منطقي لكل كائن في قاعدة البيانات.**  
3️⃣**بيتحكم في الصلاحيات والمستخدمين اللي يقدروا يشوفوا الجداول والوظايف.**

## 🔹 **6. عيلة الـ UNION 🏆**

📌 **يعني إيه؟**  
مجموعة دوال بتستخدم لدمج نتائج أكتر من استعلام مع بعض، لكن ليها شرطين أساسيين:  
✅ **نفس عدد الأعمدة في كل الاستعلامات.**  
✅ **نفس نوع البيانات في كل الأعمدة.**

### ✨ **أمثلة عملية:**

```sql
-- دمج بيانات بدون تكرار
SELECT Name, Salary FROM Employees_A
UNION
SELECT Name, Salary FROM Employees_B;
```

🔍 **هنا** الـ `UNION` هيجيب كل البيانات بس **من غير تكرار**.

```sql
-- دمج البيانات مع السماح بالتكرار
SELECT Name, Salary FROM Employees_A
UNION ALL
SELECT Name, Salary FROM Employees_B;
```

🔍 **هنا** الـ `UNION ALL` هيجيب كل البيانات **بالتكرار**.

```sql
-- جلب القيم المشتركة فقط
SELECT Name, Salary FROM Employees_A
INTERSECT
SELECT Name, Salary FROM Employees_B;
```

🔍 **هنا** `INTERSECT` هيجيب **القيم المشتركة بس** بين الجدولين.

```sql
-- جلب القيم اللي في الجدول الأول ومش موجودة في الجدول التاني
SELECT Name, Salary FROM Employees_A
EXCEPT
SELECT Name, Salary FROM Employees_B;
```

🔍 **هنا** `EXCEPT` هيجيب **البيانات اللي في الجدول الأول بس، ومش موجودة في الجدول التاني**.
