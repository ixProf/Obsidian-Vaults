# Reference Notes

Factual reference material that supports work but is not an argument or a distilled idea.

Examples:

- Tool behaviour and release notes (e.g. [[20 Zettelkasten/Reference Notes/Obsidian 1.11 Release Notes|Obsidian 1.11 Release Notes]]).
- Prompt patterns and reusable instructions (e.g. [[20 Zettelkasten/Reference Notes/Prompt|Prompt]]).
- Cheat sheets and lookup tables.

## Rules

- Keep the note factual and attributable.
- Link the tool, source, or context it belongs to.
- If the material becomes an argument or a reusable idea, promote a separate Permanent Note instead of expanding this layer.
