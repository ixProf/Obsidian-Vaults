## Parallel Tracks

Don't study the roadmap as one straight line.

**CS / Systems**  
→ Algorithms → OS → Networking → Databases → Concurrency

**Distributed Systems**  
→ RPC → Failures → Replication → Consistency → Consensus → Transactions → Sharding

**Research**  
→ Papers → Literature Review → Research Gaps → Experiments → Research Project

**Projects**  
→ Concurrent Server → RPC → MapReduce → Raft → KV Store → Sharding

**English**  
→ Technical Reading → Vocabulary → Writing → Speaking → Academic Communication
