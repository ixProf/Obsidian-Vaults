**8. The time needed to perform an integrity check and determine the appropriate output link for a packet.**

- A. Transmission delay
    
- B. Propagation delay
    
- C. **Processing delay**
    
- D. Queueing delay
    

> **الإجابة الصحيحة:** Processing delay

**9. The time spent transmitting the bits of a packet into the link.**

- A. **Transmission delay**
    
- B. Propagation delay
    
- C. Processing delay
    
- D. Queueing delay
    

> **الإجابة الصحيحة:** Transmission delay

**10. One of the fields in a UDP segment header is:**

- A. Sequence number
    
- B. **Internet checksum**
    
- C. Flow control window
    
- D. Acknowledgement number
    

> **الإجابة الصحيحة:** Internet checksum

**11. In the client-server approach to network applications:**

- A. **There is a server with a well known server IP address.**
    
- B. There is not a server that is always on.
    
- C. The server IP address is always changing.
    
- D. None of the above.
    

> **الإجابة الصحيحة:** There is a server with a well known server IP address.

**12. The purpose of a conditional HTTP GET is to:**

- A. Allow a server to track user behavior.
    
- B. **Allow a server to send the object only if it has changed since the last time it was sent.**
    
- C. Secure the connection between client and server.
    
- D. Speed up the DNS lookup.
    

> **الإجابة الصحيحة:** Allow a server to send the object only if it has changed since the last time it was sent.
