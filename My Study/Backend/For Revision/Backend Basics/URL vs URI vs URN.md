# URI vs URL vs URN

أسهل طريقة تحفظهم:

> **الـ URI هو الهوية، والـ URL هو العنوان، والـ URN هو الاسم.**

تخيل شخص:

- **الهوية** = الرقم القومي
- **العنوان** = مكان السكن
- **الاسم** = محمود
    

نفس الفكرة مع الموارد (Resources).

---

# أولًا: URI (Uniform Resource Identifier)

الـ **URI** هو أي حاجة بتستخدم علشان تعرف أو تميز Resource.

يعني هو المصطلح العام.

أي Resource ليها URI.

ممكن يكون:

- URL
    
- أو URN
    

يعني:

```
URI
├── URL
└── URN
```

---

# ثانيًا: URL (Uniform Resource Locator)

الـ URL نوع من أنواع الـ URI.

وظيفته:

> يقولك **فين الـ Resource** وإزاي توصله.

يعني بيحتوي على:

- البروتوكول
- المكان

مثال

```
https://www.google.com
```

فيه

```
https://
```

دي اسمها **Protocol (Scheme)**

وفيه

```
www.google.com
```

وده مكان الموقع.

إذن تقدر تفتحه في المتصفح.

---

مثال تاني

```
https://api.example.com/products/5
```

ده URL لأنه بيقول:

- استخدم HTTPS
    
- وروح للسيرفر ده
    
- وهات الـ Resource ده
    

---

# ثالثًا: URN (Uniform Resource Name)

الـ URN برضو نوع من أنواع الـ URI.

لكن مش بيقولك مكان الحاجة.

هو بيسميها فقط.

مثال

```
urn:isbn:0451450523
```

ده ISBN لكتاب.

هو عرفك الكتاب نفسه.

لكن مقالش:

- موجود فين
- على أي موقع
- في أي مكتبة
    

يعني مجرد اسم دائم.

---

# العلاقة بينهم

```
                URI
               /   \
            URL    URN
```

كل URL هو URI.

لكن مش كل URI يبقى URL.

---

# مثال من الواقع

تخيل صاحبك محمود.

## الاسم

```
Mahmoud
```

ده زي

```
URN
```

بيعرف مين الشخص.

لكن مش بيقول ساكن فين.

---

## العنوان

```
Egypt
Asyut
Dayrout
Street 10
```

ده زي

```
URL
```

عرفك مكانه.

---

## الهوية

الرقم القومي

ده يمثل

```
URI
```

أي حاجة تعرف الشخص.

---

# أمثلة

## URL

```
https://github.com
```

تقدر تفتحه.

---

```
https://api.myapp.com/users/5
```

ده URL.

---

## URN

```
urn:isbn:9780131103627
```

بيعرف كتاب.

---

```
urn:uuid:123e4567-e89b-12d3-a456-426614174000
```

بيعرف Object معين.

---

# في الـ REST APIs

لما تعمل

```
GET /products/10
```

الـ Resource ده ليه URI.

ولو الطلب كامل بالشكل ده:

```
https://api.store.com/products/10
```

فده **URL**، وهو في نفس الوقت **URI** لأنه بيحدد المورد ويحدد مكانه.

---

# امتى أقول URL؟

لو بتتكلم عن:

- لينك موقع
    
- لينك API
    
- لينك صورة
    
- لينك ملف
    

قول URL.

مثال

```
https://youtube.com
```

---

# امتى أقول URI؟

لو بتتكلم في مفاهيم عامة أو في REST API Design.

مثلاً

```
/users/1
```

ده بنسميه غالبًا Resource URI.

---

# ملخص سريع

|المصطلح|وظيفته|مثال|
|---|---|---|
|**URI**|أي مُعرّف (Identifier) للـ Resource|`mailto:john@example.com`، `https://google.com`، `urn:isbn:0451450523`|
|**URL**|يحدد مكان الـ Resource وطريقة الوصول إليه|`https://google.com`|
|**URN**|اسم دائم للـ Resource بدون مكانه|`urn:isbn:0451450523`|

## قاعدة تحفظها في 10 ثواني

- **URI = Identifier** → أي حاجة تعرف الـ Resource.
    
- **URL = Location** → تعرفك فين الـ Resource وإزاي توصله.
    
- **URN = Name** → تعرفك اسم الـ Resource فقط.
    

**الخلاصة:** في شغل الـ Web والـ Backend، أغلب اللي بتتعامل معاه هو **URL**، لكنه من الناحية التقنية يعتبر أيضًا **URI** لأنه نوع من أنواع الـ URI.
