# Literature Notes

Notes written **from a specific source**: a book, paper, course, lecture, documentation page, or article.

## Rules

- Keep an explicit, verifiable source link. A Literature Note is never detached from its source.
- Record bibliographic details when known: author, title, edition, year, chapter, page or section.
- Preserve the source's argument and the user's annotations; do not silently rewrite them.
- Reading notes stay here; they are not automatically Permanent Notes.
- When an idea is extracted, link the new Permanent Note back to this note and keep this note intact.

## Current groups

- DDIA chapter notes: `DDIA/Chapter 1`, `DDIA/Chapter 2`
- Book notes: *System Design Interview* (Alex Xu), *Learning Go* (Jon Bodner)
- Course and lecture notes that were moved here as reading notes

## Naming

Use the source's real title. For chapter notes, prefix with the book abbreviation, e.g. `DDIA — Reliability.md`.
