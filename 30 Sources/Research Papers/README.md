# Research Papers

Source folder for academic papers. No paper files have been moved here yet.

## Rules

- Store the paper file here when one exists; keep the original filename.
- Write the reading note in [[20 Zettelkasten/Literature Notes/README|Literature Notes]] and link it back to the paper.
- Do not create placeholder notes for papers that are only planned.
- Record bibliographic details only when they are verifiable.
