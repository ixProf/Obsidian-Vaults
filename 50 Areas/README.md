## Rules

- An Area is an ongoing responsibility; a Project is a finite deliverable.
- Do not archive an Area when a project inside it ends.
- Link relevant MOCs and real notes.
- Personal and career material stays here; technical knowledge belongs in [[20 Zettelkasten/README|Zettelkasten]].
