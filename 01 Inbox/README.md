# Inbox

Capture first, organise later.

## What goes here

- Fleeting thoughts and questions.
- Clippings that have not been processed.
- Notes that do not yet have a domain.
- Reminders to read or verify something.

## What does not go here

- Finished atomic notes.
- Project documentation.
- TaskNotes or Tasks content.
- Attachments (use `Attachment` until Stage 5).

## Processing

1. Read the note.
2. Decide its type: permanent, literature, project, or archive.
3. Move it to `20 Knowledge/<Domain>`, `30 Projects`, or `90 Archive`.
4. Add frontmatter using the matching template.
5. Link it to a domain MOC and to real related notes.
6. Leave a link in the note if it came from a source.

## Current state

Empty at the start of the refactor. New captures appear here.
