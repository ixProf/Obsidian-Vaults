# Quarantine

Material that cannot be classified safely yet.

## When to use it

- A note has conflicting content that cannot be merged.
- A file may be a duplicate but the difference is not understood.
- A link target is missing and the intent is unclear.
- A rename or move would be destructive without review.

## Rules

- Never delete.
- Add a header explaining why the item is here.
- Link the item from [[00 System/Review Report]].
- Resolve or archive it after review.
