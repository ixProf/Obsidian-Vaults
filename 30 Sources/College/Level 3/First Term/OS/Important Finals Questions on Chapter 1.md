### **أسئلة من امتحان Final 2025 (الفصل الثاني)**

- **السؤال:** In which mode does the operating system execute system calls?
    
    - Protected mode.
        
    - Kernel mode.
        
    - Virtual mode.
        
    - User mode.
        
    - **الإجابة الصحيحة:** **Kernel mode.**.
        
- **السؤال:** In which mode do user applications typically run?
    
    - System Mode.
        
    - Kernel Mode.
        
    - Supervisor Mode.
        
    - User Mode.
        
    - **الإجابة الصحيحة:** **User Mode.**.
        
- **السؤال:** How does the DMA controller inform the CPU that the transfer is complete?
    
    - By sending a signal to the MMU.
        
    - By writing a flag to the hard drive.
        
    - By sending a message through the memory bus.
        
    - By triggering an interrupt.
        
    - **الإجابة الصحيحة:** **By triggering an interrupt.**.
        
- **السؤال:** What is an interrupt in an operating system?
    
    - A signal that pauses a running process to handle an event.
        
    - A signal that terminates a running process.
        
    - A signal that restarts the operating system.
        
    - A signal that allocates memory to a process.
        
    - **الإجابة الصحيحة:** **A signal that pauses a running process to handle an event.**. (يتوافق مع ).
        
- **السؤال:** What is the benefit of using DMA?
    
    - Simplified process scheduling.
        
    - Reduced memory usage.
        
    - Increased CPU utilization.
        
    - Improved I/O performance and reduced CPU overhead.
        
    - **الإجابة الصحيحة:** **Improved I/O performance and reduced CPU overhead.**.
        
- **السؤال:** How does a user program request a service from the operating system?
    
    - By writing data to a specific memory location.
        
    - By generating a hardware interrupt directly.
        
    - By directly accessing kernel memory.
        
    - By executing a system call.
        
    - **الإجابة الصحيحة:** **By executing a system call.**. (يتوافق مع ).

### **أسئلة من امتحان Final 2025 (أهلية)**

- **السؤال:** Which mode of operation provides direct access to system hardware and memory?
    
    - User mode
        
    - Kernel mode
        
    - Protected mode
        
    - Virtual mode
        
    - **الإجابة الصحيحة:** **Kernel mode**. (يتوافق مع تعريف الـ Kernel Mode في ).
        
- **السؤال:** When a user process needs to perform an I/O operation, it typically:
    
    - Directly accesses the I/O device.
        
    - Executes a system call to request the kernel to perform the operation.
        
    - Switches to kernel mode and performs the operation itself.
        
    - Pauses execution until the I/O device becomes available.
        
    - **الإجابة الصحيحة:** **Executes a system call to request the kernel to perform the operation.**.
        
- **السؤال:** When a system call is made, the CPU typically switches from:
    
    - Kernel mode to user mode
        
    - User mode to kernel mode
        
    - Protected mode to user mode
        
    - Virtual mode to kernel mode
        
    - **الإجابة الصحيحة:** **User mode to kernel mode**. (يتوافق مع ).
