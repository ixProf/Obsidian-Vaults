- هنمسك دايركتوري دايركتوري نتكلم عليه
	- الـusr : موجود فيه الـSoftware والـLibraries الي الProgram الي نزلناها ممكن نحتاجها

	- الـvar: بيكون فيها الـVariable Data ويكون فيه الLogs 
		- الـtemp: بيشيل فيها ال temprory files 
	- الـdev -> فيه كل ال Device Files 
	- الـrun -> عبارة عن Variable Data برضو بس خاصة بعملية ال booting
	- الhome -> بيكون فيه ال home directory بتاع ال user

في حاجه اسمها
- الـAbsolute Path
	- هو عبارة عن <mark style="background-color: #FFF3A3A6;">الباث الكامل من اول ال root لحد المكان</mark> الي عايز تروحله مثلا يعني
	![[Pasted image 20260730104554.png]]
	- عايز تروح من الروت ل bin ف انت هتكتب من اول الروت لحد الbin في امر جديد اسمه cd وهو اختصار لكلمة "Change Directory"
```bash
cd /usr/bin
```
- الـRelative Path: اما بقى هنا لو انت مثلا عايز تروح لمكان هو <mark style="background-color: #FFF3A3A6;">already في الباث بتاعك</mark> وليكن مثلا انت واقف في ال bin ف انت محتاج مثلا تروح لل x ف مش هتكتب الباث كامل لا انت يدوبك هتكتب
```bash
cd x
```

![[Pasted image 20260730105623.png]]

الرسمة دي بسيطة بتوضحلك حاجه او قاعدة معينة

طالما الحاجة دي جوا حاجه معينة فالي ==جوا بالنسبة للي برا Relative== 
ف انت لو واقف مثلا في ال usr ومحتاج تروح لل bin فبشكل بسيط انت هتروح كاتب
```bash
cd bin
```

طب انت دخلت من bin لل x وعايز توصل لل usr 
فالحالة دي x ملهاش علاقة بال usr ف انت هتلجأ لل Absolute Path 
```bash
cd /usr
```

ونفس الكلام لو انت حابب تروح لل y وانت واقف في ال bin ف ال y ملهاش علاقة بال bin ف انت هتكتب الباث بشكل كامل زي كدا

```bash
cd bin/x/y
```

- بداية البلوك الي بيتكتب فيه الفولدرز او الفايلات بيكون ليه حاجه اسمها iNode (Identifer Node) ==ودا بيبدأ يقولك الفايل بتاعي بدأ منين وانتهى فين في البلوك الواحد او الدايركتوري فيه ايه ومفيهوش ايه==

- ولنفترض ان بنتكلم عن Root Directory بيتعرف معاه بشكل تلقائي حاجه اسمها ==inode table== ودا بيكون شايل المعلومات الي فيه الي هو الدايركتوريز الي فيه، وكل دايركتوريه ليه سايز معين وليه كمان inode table خاص بيه

ومثلا في اتنين يوزر في الهوم وعندك جوا يوزر معين فايل ف اليوزر دا بما انه دايركتوري ف هيكون فيه INode table كمان ف هيكون بالشكل دا

- احنا بنعرف الحاجات دي علشان ال Links وعندنا نوعين منه
	- عندك ال Soft Link: وهو ==شبيه بال Shortcut== الي في الويندوز الي هو كأن عندك حاجه بتشاور على حاجه <mark style="background-color: #FFF3A3A6;">لو عدلت فيها هتسمع في الحاجه الي عاملها لينك</mark> وعلشان تعمله هتكتب الامر دا
	```bash
	ln -s "file 1" "file 2"
	```

![[Pasted image 20260730115329.png]]

- النوع التاني وهو ال Hard Link
	- الـHard Link فكرته انه بيخلي فايلين يشاوروا على نفس ال INode 
	```bash
	ln "file 1" "file 2"
	```

![[Pasted image 20260730115739.png]]

- الSoft Link: بيخليك تشاور على الفايل نفسه يعني لو عملت سوفت لينك لفايل ف السوفت دا هيشاور على الفايل نفسه لكن هنا لو مسحت هيحصل مشكلة
	- بيحصل بين الدايركتوريز والفايلز 
- الـHard Link: بيخليك انت والفايل تشاوروا على ال iNode بتاع ال File يعني الهارد نفسه فلو مسحت مش هيحصله اي مشكلة
