# Data Query Language (DQL) - SELECT
- **الغرض**: DQL هي جزء من SQL بتستخدمها عشان تجيب بيانات من قاعدة البيانات من غير ما تغير فيها حاجة. الأمر الرئيسي هو `SELECT`.

- **أمثلة**:
  - **Select All Data**:  
    ترجعلك كل البيانات اللي في جدول `Student`.  
    ```sql
    SELECT * 
    FROM Student
    ```

  - **Select Specific Columns**:  
    يرجعلك عمود معين في جدول معين، زي الاسم الأول والأخير بس.  
    ```sql
    SELECT St_Fname, St_Lname 
    FROM Student
    ```

  - **Concatenation**:  
    يجمعلك الداتا في عمود معين ويحطها تحت اسم معين، زي الاسم الكامل.  
    ```sql
    SELECT [Full Name] = St_Fname + ' ' + St_Lname 
    FROM Student
    ```

---

## Where:
- **Age less than 23**:  
  بتجيب كل الطلاب اللي أعمارهم أقل من 23.  
  ```sql
  SELECT * 
  FROM Student 
  WHERE St_Age < 23
  ```

---
- **Specific addresses**:  
  بتجيب الطلاب اللي ساكنين في أماكن معينة زي الإسكندرية، المنصورة، القاهرة.  
  ```sql
  SELECT * 
  FROM Student 
  WHERE St_Address IN ('Alex', 'Mansoura', 'Cairo')
  ```

- **Excluding addresses**:  
  بتجيب الطلاب اللي مش ساكنين في الإسكندرية، المنصورة، القاهرة.  
  ```sql
  SELECT * 
  FROM Student 
  WHERE St_Address NOT IN ('Alex', 'Mansoura', 'Cairo')
  ```

- **Pattern Matching with LIKE**:  
  - **Second character is 'a'**:  
    بتجيب أسماء الطلاب اللي الحرف التاني فيها 'a'.  
    ```sql
    SELECT St_Lname 
    FROM Student 
    WHERE St_Lname LIKE '_a%'
    ```
  - **Ends with '%'**:  
    بتجيب الأسماء اللي بتخلّص بـ '%'.  
    ```sql
    SELECT St_Fname 
    FROM Student 
    WHERE St_Fname LIKE '%[%]'
    ```
    ملحوظة: `_` يعني حرف واحد، `%` يعني صفر أو أكتر من الحروف.
  - Include '%' at any position
الحروف دي ممكن تكون موجودة في الاول او الاخر او النص بنستخدم % فالاول والاخر ووسطها نحط الي بنبحث عنها
```sql
SELECT * 
FROM shows 
WHERE name LIKE '%the%';
```
بيدور على اي كلمة فيها the بغض النظر الحروف دي كانت في الاخر ولا في الاول

---

## Distinct:
- **Removing Duplicates**:  
  بتحذف المتكرر من البيانات، يعني لو في أسماء متكررة هتظهر مرة واحدة بس.  
  ```sql
  SELECT DISTINCT St_Fname, St_Lname 
  FROM Student
  ```

---

## Order by:
- **Sorting**:  
  تستخدم في الترتيب، يعني بترتب الأسماء حسب الاسم الأول والأخير.  
  ```sql
  SELECT St_Fname, St_Lname 
  FROM Student 
  ORDER BY St_Fname, St_Lname
  ```
بالنسبة للأرقام فالترتيب ال Default بتاعه بيكون تصاعدي (من الأقل للاكبر) مثلا

```SQL
SELECT *
FROM Student
ORDER BY age;
```
لكن لو حابين نعملها من تنازلياً بنستخدم كلمة `DESC`
```SQL
SELECT *
FROM Student
ORDER BY age DESC;
```

## 🟦 ما هو `BETWEEN`؟

`BETWEEN` هو عامل (Operator) يُستخدم في جملة `WHERE` لتحديد **نطاق** من القيم (Range) — سواء كانت أرقام، تواريخ، أو نصوص — ويُرجع فقط الصفوف التي تقع **ضمن هذا النطاق** (بما في ذلك الحدين).

---

## ✅ حالات الاستخدام:

### 1. **القيم الرقمية (Numbers)**

#### ✅ استخدام شائع لتحديد نطاق من الأرقام.

**مثال: إرجاع المنتجات التي سعرها بين 100 و300:**

```sql
SELECT *
FROM products
WHERE price BETWEEN 100 AND 300;
```

> يشمل السعر 100 و300 أيضًا.

---

### 2. **التواريخ (Dates)**

#### ✅ تُستخدم لتصفية البيانات حسب فترة زمنية.

**مثال: إرجاع الطلبات بين 1 يناير 2024 و31 مارس 2024:**

```sql
SELECT *
FROM orders
WHERE order_date BETWEEN '2024-01-01' AND '2024-03-31';
```

> تأكد أن التاريخ بصيغة صحيحة وداخل علامات اقتباس.

---

### 3. **النصوص (Text)**

#### ✅ يُستخدم لتحديد نطاق أبجدي.

**مثال: إرجاع العملاء الذين تبدأ أسماؤهم بحروف من A إلى D:**

```sql
SELECT *
FROM customers
WHERE name BETWEEN 'A' AND 'D';
```

🔸 ملاحظات مهمة:

- يشمل الكلمات التي تبدأ بـ 'A', 'B', 'C', و 'D' فقط **إذا كانت الكلمة تساوي 'D' فقط**.
    
- لا يشمل الكلمات التي تبدأ بـ 'D' متبوعة بحروف أخرى، مثل: `'David'`.
    

---

### 4. **مع القيم العكسية (Reversed range)**

> يمكنك كتابة `BETWEEN x AND y` فقط إذا كان `x <= y`.  
> إذا عكست القيم، فلن تُرجع النتيجة أي صف.

**خطأ شائع:**

```sql
-- هذا لا يعمل كما تتوقع
SELECT *
FROM orders
WHERE price BETWEEN 500 AND 100;  -- لا يُرجع شيء
```

---

### 5. **مع NOT BETWEEN**

#### ✅ لعكس النطاق — إرجاع الصفوف **خارج** النطاق.

**مثال: إرجاع المنتجات التي سعرها أقل من 100 أو أكثر من 300:**

```sql
SELECT *
FROM products
WHERE price NOT BETWEEN 100 AND 300;
```
 الفرق بين:

```sql
WHERE age BETWEEN 18 AND 22;
```

و

```sql
WHERE age NOT BETWEEN 18 AND 22;
```

هو أن الأول **يختار القيم داخل النطاق**، والثاني **يستبعد القيم داخل النطاق**.

---

## 🔍 الفرق بالتفصيل:

|الشرط|المعنى|
|---|---|
|`BETWEEN 18 AND 22`|✅ يُرجع الصفوف التي تكون قيمة العمر فيها من **18 إلى 22** (بما في ذلك 18 و22).|
|`NOT BETWEEN 18 AND 22`|❌ يُرجع الصفوف التي تكون قيمة العمر فيها **أقل من 18 أو أكبر من 22**.|

---


🔽 النتيجة:

## 📝 ملاحظات عامة:

- `BETWEEN` يشمل القيم الحدية (Inclusive).
    
- يُمكن استخدامه مع أنواع البيانات التالية:
    
    - `INT` (أعداد صحيحة)
        
    - `FLOAT/DECIMAL` (أعداد عشرية)
        
    - `DATE/DATETIME` (تواريخ)
        
    - `VARCHAR/CHAR` (نصوص)
        

---

## 💡 نصيحة:

عند استخدام `BETWEEN` مع النصوص، وكنت تريد تضمين كلمات مثل "David"، استخدم شرطًا بديلًا مثل:

```sql
WHERE name >= 'A' AND name < 'E'
```

لأنه يشمل كل شيء من 'A' إلى قبل 'E'.

## ✅ ما هو `GROUP BY`؟

`GROUP BY` هي عبارة تُستخدم في SQL **لتجميع الصفوف التي تحتوي على نفس القيمة في عمود أو أكثر**، ثم تُطبق دوال التجميع (مثل `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`) على كل مجموعة.

---

## 📌 الفكرة الأساسية:

> "قم بتقسيم البيانات إلى مجموعات حسب عمود معين، ثم احسب **قيمة مجمعة** لكل مجموعة."

---

## 🧠 متى تستخدم `GROUP BY`؟

تستخدم عندما:

- تريد **إحصاء** أو **تلخيص** بيانات بناءً على قيم مشتركة في عمود.
    
- تستخدم دوال مثل:
    
    - `COUNT()` لحساب عدد الصفوف
        
    - `SUM()` لحساب مجموع القيم
        
    - `AVG()` لحساب المتوسط
        
    - `MAX()` و`MIN()` لأقصى/أدنى قيمة
        

---

## 📊 مثال 1: عدد الطلاب في كل نادي

نفترض عندنا الجدول التالي (من قاعدة بياناتك):

### جدول Student_Club:

|StudentID|ClubID|JoinDate|
|---|---|---|
|1|101|2023-01-15|
|1|103|2023-03-10|
|2|101|2023-02-20|
|2|102|2023-04-05|
|3|103|2023-01-30|
|4|102|2023-05-12|

### نريد: **عدد الطلاب في كل نادي** (أي عدد المشاركين في كل `ClubID`)

```sql
SELECT ClubID, COUNT(StudentID) AS NumOfStudents
FROM Student_Club
GROUP BY ClubID;
```

🔍 **الشرح:**

- `GROUP BY ClubID`: يجمع الصفوف حسب رقم النادي.
    
- `COUNT(StudentID)`: يعدّ كم طالبًا في كل نادي.
    
- `AS NumOfStudents`: اسم العمود الناتج.
    

---

### ✅ النتيجة:

|ClubID|NumOfStudents|
|---|---|
|101|2|
|102|2|
|103|2|

---

## 📊 مثال 2: متوسط أعمار الطلاب حسب النوع (الجنس)

نفترض جدول `Students`:

|StudentID|St_Name|Age|Gender|
|---|---|---|---|
|1|Ahmed Khaled|20|Male|
|2|Fatima Noor|19|Female|
|3|Omar Ali|21|Male|
|4|Hala Salem|22|Female|

نريد: **متوسط أعمار الطلاب حسب النوع (ذكور وإناث):**

```sql
SELECT Gender, AVG(Age) AS AverageAge
FROM Students
GROUP BY Gender;
```

### ✅ النتيجة:

|Gender|AverageAge|
|---|---|
|Male|20.5|
|Female|20.5|

---

## ⚠️ ملاحظات مهمة:

### 1. أي عمود في `SELECT` **يجب أن يكون إما:**

- جزءًا من `GROUP BY`
    
- أو يكون داخل دالة تجميعية (`SUM`, `COUNT`, إلخ)
    

❌ مثال خاطئ:

```sql
SELECT Gender, Age FROM Students GROUP BY Gender;
```

هذا غير صحيح لأن `Age` ليست ضمن `GROUP BY` ولا داخل دالة.

✅ الصحيح:

```sql
SELECT Gender, MAX(Age) FROM Students GROUP BY Gender;
```

---

### 2. يمكنك استخدام `GROUP BY` مع أكثر من عمود:

```sql
SELECT Gender, Age, COUNT(*) AS Count
FROM Students
GROUP BY Gender, Age;
```

> هذا سيجمع حسب **كل مجموعة من النوع والعمر معًا**.

---

## 🎯 `GROUP BY` مع `JOIN`

نأخذ مثالًا حقيقيًا من قاعدة بياناتك:

### نريد: عدد الطلاب المشاركين في كل نادي **باسمه الحقيقي**:

```sql
SELECT C.ClubName, COUNT(SC.StudentID) AS NumOfMembers
FROM Student_Club SC
JOIN Clubs C ON SC.ClubID = C.ClubID
GROUP BY C.ClubName;
```

---

## 🧠 خلاصة:

|المبدأ|الشرح|
|---|---|
|الغرض|تجميع البيانات حسب قيمة معينة|
|يستخدم مع|دوال التجميع (COUNT, SUM, AVG...)|
|في جملة SELECT|يجب استخدام الأعمدة داخل GROUP BY أو ضمن دالة|
|يدعم أعمدة متعددة|نعم، يمكن استخدام أكثر من عمود في GROUP BY|
|يمكن دمجه مع JOIN|نعم، بشكل شائع جدًا في تقارير وتحليلات البيانات|

## 🔷 ما هو الاستعلام المتداخل (Nested Query)؟

هو استعلام SQL **يتم وضعه داخل استعلام آخر**.  
ويُستخدم عندما تحتاج إلى استخدام نتيجة استعلام واحد كجزء من استعلام آخر.

يُكتب الاستعلام الداخلي عادة داخل الأقواس `( )`، ويتم تنفيذه أولًا.

---

## ✅ أنواع الاستعلامات المتداخلة:

### 1. **في جملة `WHERE`** (الأكثر شيوعًا)

تُستخدم لتصفية النتائج باستخدام نتيجة من استعلام آخر.

#### 🧪 مثال:

لدينا جدولين:

- جدول `students`:
    

|id|name|class_id|
|---|---|---|
|1|Ali|101|
|2|Sara|102|
|3|Omar|101|

- جدول `classes`:
    

|id|name|
|---|---|
|101|Science|
|102|Literature|

---

### 🎯 الهدف:

نريد إرجاع أسماء الطلاب الذين يدرسون في **قسم Science فقط**.

#### 🔽 الاستعلام المتداخل:

```sql
SELECT name
FROM students
WHERE class_id = (
    SELECT id
    FROM classes
    WHERE name = 'Science'
);
```

> 🔍 شرح:

- **الاستعلام الداخلي**:
    
    ```sql
    SELECT id FROM classes WHERE name = 'Science'
    ```
    
    يُرجع: `101`
    
- **الاستعلام الخارجي**:  
    يبحث عن الطلاب الذين `class_id = 101`
    

---

### 2. **في جملة `SELECT`**

يمكنك استخدام استعلام فرعي لحساب قيمة معينة لكل صف.

#### 📌 مثال:

```sql
SELECT name,
       (SELECT COUNT(*) FROM classes) AS total_classes
FROM students;
```

> يعرض أسماء الطلاب، ومع كل اسم يظهر عدد الصفوف في جدول `classes`.

---

### 3. **في جملة `FROM`**

يمكنك استخدام استعلام فرعي كجدول مؤقت.

#### 🧪 مثال:

```sql
SELECT avg_age.avg
FROM (
    SELECT AVG(age) AS avg
    FROM students
) AS avg_age;
```

---

## ⚠️ ملاحظات مهمة:

- يتم تنفيذ الاستعلام **الداخلي أولًا**.
    
- الاستعلام الداخلي يمكن أن يُرجع:
    
    - **قيمة واحدة** (مثل رقم أو اسم).
        
    - **عدة قيم** (باستخدام `IN`).
        
    - **جدول كامل** (إذا استخدمته في `FROM`).
        

---

## 🎯 مثال عملي مع `IN`:

```sql
SELECT name
FROM students
WHERE class_id IN (
    SELECT id
    FROM classes
    WHERE name IN ('Science', 'Math')
);
```

# Joins
- **الغرض**: الـ Joins بتجمع بيانات من أكتر من جدول بناءً على عمود مشترك بينهم.

- **الأنواع**:
  1. **Cross Join**:  
     بيجمع كل صف من جدول مع كل صف من جدول تاني (يعني ضرب ديكارتي).  
     ```sql
     SELECT S.St_Fname, C.Crs_Name 
     FROM Student S 
     CROSS JOIN Course C
     ```
![[CrossJoin 1.png]]


  2. **Inner Join**:  
     بيرجع الصفوف اللي بتتطابق في الجدولين بس.  
     ```sql
     SELECT S.St_Fname, D.Dept_Name 
     FROM Student S 
     INNER JOIN Department D 
     ON D.Dept_Id = S.Dept_Id
     ```

  3. **Outer Join**:
     - **Left Join**:  
       بيرجع كل الصفوف من الجدول الأيسر، ولو مفيش تطابق في الجدول الأيمن يحط `NULL`.  
       ```sql
       SELECT S.St_Fname, D.Dept_Name 
       FROM Student S 
       LEFT JOIN Department D 
       ON D.Dept_Id = S.Dept_Id
       ```
     - **Right Join**:  
       بيرجع كل الصفوف من الجدول الأيمن، ولو مفيش تطابق في الجدول الأيسر يحط `NULL`.  
       ```sql
       SELECT S.St_Fname, D.Dept_Name 
       FROM Student S 
       RIGHT JOIN Department D 
       ON D.Dept_Id = S.Dept_Id
       ```
     - **Full Join**:  
       بيرجع كل الصفوف من الجدولين، ولو مفيش تطابق يحط `NULL`.  
       ```sql
       SELECT S.St_Fname, D.Dept_Name 
       FROM Student S 
       FULL OUTER JOIN Department D 
       ON D.Dept_Id = S.Dept_Id
       ```

![[Joins.png]]

  4. **Self Join**:  
     بيرجع بيانات من نفس الجدول، زي لما تجيب الطلاب ومشرفيهم من جدول واحد.  
     ```sql
     SELECT S.St_Fname, Super.St_Fname 
     FROM Student S 
     INNER JOIN Student Super 
     ON Super.St_Id = S.St_super
     ```

![[SelefJoin.png]]
  4. **Multi-Table Join**:  
     بيرجع بيانات من أكتر من جدولين مع بعض.  
     ```sql
     SELECT S.St_Fname, C.Crs_Name, SC.Grade 
     FROM Student S 
     INNER JOIN Stud_Course SC 
     ON S.St_Id = SC.St_Id 
     INNER JOIN Course C 
     ON C.Crs_Id = SC.Crs_Id
     ```

# 4. Join + DML (Update)
- **Update with Join**:  
  بيعدل بيانات في جدول بناءً على شرط من جدول تاني، زي لما تزود درجات الطلاب الساكنين في القاهرة بـ 10.  
  ```sql
  UPDATE SC 
  SET Grade = Grade + 10 
  FROM Student S 
  INNER JOIN Stud_Course SC 
  ON S.St_Id = SC.St_Id 
  WHERE S.St_Address = 'Cairo'
  ```
