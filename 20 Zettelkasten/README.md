# Zettelkasten

This folder holds **ideas**, not courses, books, or semesters. Source material stays in [[30 Sources/README|Sources]]; knowledge is distilled here.

## Layers

| Layer | Folder | Rule |
|---|---|---|
| Fleeting | [[20 Zettelkasten/Fleeting Notes/README\|Fleeting Notes]] | Quick captures awaiting processing. Not permanent. |
| Literature | [[20 Zettelkasten/Literature Notes/README\|Literature Notes]] | Notes bound to one source, with chapter/page references and attribution. |
| Permanent | [[20 Zettelkasten/Permanent Notes/README\|Permanent Notes]] | One meaningful, independently understandable idea per note. |
| Reference | [[20 Zettelkasten/Reference Notes/README\|Reference Notes]] | Factual reference material and tool notes, not arguments. |

## Working loop

1. Capture in `01 Inbox` or [[20 Zettelkasten/Fleeting Notes/README|Fleeting Notes]].
2. Read the source and write a Literature Note with an explicit source link.
3. Distil an independent idea into a Permanent Note only when it is genuinely atomic and deep enough.
4. Link the Permanent Note to its source, related notes, and the relevant domain MOC.
5. Keep the original long-form source; never replace it with extracted notes.

## Rules

- Do not create a Permanent Note for a term, a sentence, or a heading.
- Do not fabricate the user's understanding. When synthesis is required, write a proposal in `00 System/Knowledge Extraction Proposals` instead.
- Arabic content, examples, code, tables, and diagrams are preserved exactly.
- Every note keeps valid frontmatter and at least one real link.
- MOCs navigate; they do not store knowledge.
