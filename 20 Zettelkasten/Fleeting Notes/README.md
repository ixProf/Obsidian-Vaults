# Fleeting Notes

Temporary captures: questions, half-formed ideas, and fragments that are not yet ready to become Literature or Permanent Notes.

## Rules

- Keep the capture close to its original wording.
- Process regularly: promote to a Literature Note, a Permanent Note, a project task, or archive.
- Do not treat a Fleeting Note as durable knowledge.
- If a capture belongs to an active source, link that source before promoting it.

## Processing

1. Identify what the fragment is about.
2. Find or create the source-bound Literature Note.
3. Decide whether an independent idea exists.
4. Move or rewrite into [[20 Zettelkasten/Permanent Notes/README|Permanent Notes]] only when justified.
5. Delete nothing; archive superseded fragments in `90 Archive`.
