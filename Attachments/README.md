## Rules

- New attachments go to `Attachments/Uncategorized` by default.
- Move an image into a topic folder only when its topic is clear, and update its gallery note.
- Never rename an image: filenames are the link key.
- The legacy `Attachment/` folder keeps PDFs and protected files only.
